Plan de Clase: Document Object Model (DOM)

Guía didáctica organizada en dos sesiones de 2 horas para abarcar de forma integral el ecosistema del navegador y la manipulación del árbol de documentos.

Parte 1: Jerarquía del Navegador, Selección y Estructura

  • El Entorno del Navegador: Objeto global window y sus subobjetos integrados (document, location, history, navigator, screen).
  • Raíz del Documento: Objeto document y árbol de nodos HTML.
  • Selección de Elementos: getElementById(), getElementsByClassName(), getElementsByTagName(), querySelector() y querySelectorAll().
  • Modificación de Nodos: Propiedades de contenido (innerHTML, textContent) y métodos de estructura (createElement(), appendChild(), removeChild()).

Parte 2: Atributos, Estilos, Colecciones y Eventos

  • Colecciones de Nodos: Diferencias entre HTMLCollection (colección viva) y NodeList (colección estática).
  • Atributos y Clases: Objeto Attr, NamedNodeMap (attributes), métodos de atributo (setAttribute(), getAttribute()) y classList.
  • Estilos CSS Dinámicos: Manipulación de element.style, métodos setProperty() y estilos calculados con window.getComputedStyle().
  • Manejo de Eventos: Escuchadores addEventListener(), jerarquía de Event Object (MouseEvent, KeyboardEvent) y control de flujo (preventDefault(), stopPropagation()).

1. Window Object

Representa la ventana del navegador que contiene el documento. Es el objeto global en JavaScript ejecutable en el cliente.

Área de Pruebas Interactiva
El resultado de la interacción aparecerá aquí...
// Métodos de interacción y temporizadores del objeto Window function runAlert() { window.alert("¡Mensaje emergente enviado desde window.alert()!"); } function runConfirm() { let userChoice = window.confirm("¿Deseas confirmar la acción?"); document.getElementById("out-window").textContent = "window.confirm(): " + userChoice; } function runPrompt() { let name = window.prompt("Escribe tu nombre:", "Estudiante"); document.getElementById("out-window").textContent = "window.prompt(): " + name; } function runTimer() { document.getElementById("out-window").textContent = "Esperando 2 segundos..."; window.setTimeout(() => { document.getElementById("out-window").textContent = "¡Ejecutado tras 2000ms mediante window.setTimeout()!"; }, 2000); } function getDimensions() { let w = window.innerWidth; let h = window.innerHeight; document.getElementById("out-window").textContent = `Viewport: ${w}px de ancho x ${h}px de alto`; }
Explicación Didáctica:
El objeto window encapsula todas las funciones globales del navegador. Métodos como alert(), confirm() y prompt() detienen temporalmente la ejecución del hilo principal para interactuar con el usuario. Por su parte, setTimeout() permite programar la ejecución asíncrona de funciones tras un intervalo especificado en milisegundos.

2. Window Location Object

Contiene información sobre la URL del documento actual y proporciona métodos para redirigir o recargar la página.

Área de Pruebas Interactiva
Haz clic en inspeccionar para analizar las propiedades de la URL...
// Propiedades de inspección de dirección URL function inspectLocation() { const loc = window.location; let info = `href: ${loc.href}\n` + `protocol: ${loc.protocol}\n` + `hostname: ${loc.hostname}\n` + `pathname: ${loc.pathname}\n` + `origin: ${loc.origin}`; document.getElementById("out-location").style.whiteSpace = "pre-wrap"; document.getElementById("out-location").textContent = info; } function reloadPage() { window.location.reload(); }
Explicación Didáctica:
window.location permite desglosar la dirección web en sus componentes clave: protocol (http/https), hostname (dominio) y pathname (ruta del recurso). Además, mediante métodos como assign() o replace() podemos redirigir al usuario a una nueva página, mientras que reload() actualiza la sesión actual.

3. Window History Object

Proporciona acceso al historial de navegación de la sesión del navegador en la pestaña actual.

Área de Pruebas Interactiva
Presiona para consultar la longitud del historial...
// Propiedad length y navegación en el historial function getHistoryLength() { let total = window.history.length; document.getElementById("out-history").textContent = "Páginas visitadas en la sesión (history.length): " + total; } function historyBack() { window.history.back(); }
Explicación Didáctica:
El objeto history mantiene el registro de URLs visitadas durante la sesión. Su propiedad length devuelve el número total de entradas guardadas. Métodos como back(), forward() y go(n) permiten desplazar programáticamente la navegación sin requerir intervención directa en la interfaz del navegador.

6. HTML DOM Document Object

El objeto Document es la raíz de la estructura HTML y la puerta de entrada para seleccionar y crear elementos en la página.

Área de Pruebas Interactiva
Elemento Objetivo (#out-doc-target)
// Selección de nodos y creación dinámica en el Documento function demoSelectors() { const target = document.querySelector("#out-doc-target"); target.style.backgroundColor = "#bbf7d0"; target.textContent = "¡Seleccionado con document.querySelector()!"; } function demoCreate() { const newDiv = document.createElement("div"); const newText = document.createTextNode("Nuevo párrafo dinámico agregado al contenedor."); newDiv.appendChild(newText); newDiv.style.marginTop = "8px"; newDiv.style.color = "#0284c7"; document.getElementById("sec-6").querySelector(".playground").appendChild(newDiv); }
Explicación Didáctica:
document representa el documento HTML cargado en la ventana. Métodos como querySelector() y querySelectorAll() permiten localizar nodos mediante selectores CSS modernos. Asimismo, createElement() y appendChild() permiten construir elementos e insertarlos dinámicamente en el árbol de nodos.

7. HTML DOM Element Object

Representa una etiqueta HTML individual (como div, p, a). Permite modificar su contenido y navegar entre sus nodos parientes o hijos.

Área de Pruebas Interactiva
Texto inicial dentro del contenedor
// Modificación de propiedades de contenido y navegación de jerarquía function modifyInnerHTML() { const box = document.getElementById("element-demo-box"); box.innerHTML = "Texto en negrita e HTML insertado mediante innerHTML"; } function modifyTextContent() { const box = document.getElementById("element-demo-box"); box.textContent = "Texto plano seguro insertado mediante textContent (elimina etiquetas HTML)"; } function navigateTree() { const box = document.getElementById("element-demo-box"); const parentTag = box.parentNode.tagName; const childCount = box.children.length; alert(`Elemento Padre: ${parentTag} | Cantidad de Elementos Hijos: ${childCount}`); }
Explicación Didáctica:
El objeto Element representa nodos del tipo etiqueta HTML. innerHTML interpreta etiquetas dentro del string asignado, mientras que textContent lo procesa como texto plano. Propiedades de navegación como parentNode, children, firstElementChild y nextElementSibling permiten recorrer el árbol del DOM en cualquier dirección.

Colecciones de elementos retornadas por el DOM. Difieren en su comportamiento dinámico (vivo) y los métodos que ofrecen.

Área de Pruebas Interactiva
  • Elemento 1

Resultados del análisis de colecciones...
// Comparación entre HTMLCollection (Colección Viva) y NodeList (Estática) function demoHTMLCollection() { const collection = document.getElementsByClassName("item-list"); let info = `HTMLCollection - Longitud: ${collection.length}\n` + `Elemento en índice 0 (item(0)): ${collection.item(0).textContent}`; document.getElementById("out-collections").style.whiteSpace = "pre-wrap"; document.getElementById("out-collections").textContent = info; } function demoNodeList() { const nodeList = document.querySelectorAll(".item-list"); let itemsText = []; nodeList.forEach((node, index) => { itemsText.push(`[${index}]: ${node.textContent}`); }); document.getElementById("out-collections").style.whiteSpace = "pre-wrap"; document.getElementById("out-collections").textContent = "NodeList iterada con forEach:\n" + itemsText.join("\n"); }
Explicación Didáctica:
Una HTMLCollection se actualiza automáticamente si se agregan o eliminan elementos del DOM ("colección viva"), pero solo acepta elementos HTML. Una NodeList (como la retornada por querySelectorAll()) suele ser estática y permite utilizar directamente el método forEach() para iterar sus elementos.

9. HTML DOM Attr Object & classList

Los atributos de un elemento se almacenan en una colección llamada NamedNodeMap. Además, classList facilita la gestión de clases CSS.

Área de Pruebas Interactiva
Caja de prueba para atributos y clases

// Lectura y modificación de atributos HTML y clases CSS function demoAttributes() { const el = document.getElementById("attr-target-box"); const attrMap = el.attributes; // Retorna NamedNodeMap de objetos Attr let list = []; for (let i = 0; i < attrMap.length; i++) { let attrObj = attrMap.item(i); list.push(`${attrObj.name} = "${attrObj.value}"`); } alert("NamedNodeMap (Attributes):\n" + list.join("\n")); } function demoSetAttribute() { const el = document.getElementById("attr-target-box"); el.setAttribute("data-estado", "activo"); alert("Atributo asignado: data-estado=" + el.getAttribute("data-estado")); } function demoClassList() { const el = document.getElementById("attr-target-box"); el.classList.toggle("resaltado"); if (el.classList.contains("resaltado")) { el.style.border = "2px solid #ef4444"; el.style.backgroundColor = "#fef2f2"; } else { el.style.border = "none"; el.style.backgroundColor = "#e2e8f0"; } }
Explicación Didáctica:
Cada atributo HTML es representable como un objeto Attr con propiedades name y value. La colección attributes de un elemento devuelve un NamedNodeMap. Para modificar atributos se recomiendan setAttribute() y getAttribute(), mientras que para manipular clases CSS de forma limpia se utiliza classList con sus métodos add(), remove(), toggle() y contains().

11. HTML DOM Event Object & Event Handling

Los eventos permiten ejecutar código JavaScript en respuesta a acciones del usuario. Todas las clases de eventos heredan del objeto base Event.

Área de Pruebas Interactiva
Enlace con preventDefault()
Los datos del objeto Event capturado aparecerán aquí...
// Asignación de escuchadores y análisis del objeto Event const btn = document.getElementById("event-demo-btn"); const link = document.getElementById("link-demo"); const out = document.getElementById("out-event"); btn.addEventListener("click", function(event) { let details = `Tipo de Evento (type): ${event.type}\n` + `Elemento Emisor (target): ${event.target.tagName}\n` + `Coordenadas del Clic (clientX, clientY): ${event.clientX}px, ${event.clientY}px`; out.style.whiteSpace = "pre-wrap"; out.textContent = details; }); link.addEventListener("click", function(event) { event.preventDefault(); alert("¡evento.preventDefault() ejecutado! Se bloqueó la navegación predeterminada del enlace."); });
Explicación Didáctica:
Mediante addEventListener() se registran funciones escuchadoras. Cuando ocurre la acción, el navegador instancia automáticamente un objeto derivado de Event (por ejemplo, MouseEvent para clics o KeyboardEvent para teclas). Métodos esenciales como preventDefault() anulan la acción por defecto del navegador (como el envío de formularios o saltos de hipervínculos) y stopPropagation() detiene la burbuja de propagación en la jerarquía del DOM.
